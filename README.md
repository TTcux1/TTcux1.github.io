# TTcux · staff

Личная страница-визитка: тёмный неон, дождь, частицы, печатающийся текст, плейлист с визуализатором, статус Discord, счётчик просмотров, проекты.

## Файлы
- `index.html` — вся страница
- `avatar.gif` — аватарка (облегчённая, 320×320)
- `cover.jpg` — обложка трека и иконка вкладки
- `bg.jpg` — размытый фон
- `music.mp3` — трек SPACE! (Super Slowed) — NAOMI, DRAWMEDEATH

## Настройки
Всё меняется в одном месте — блок `CONFIG` в начале `<script>` внутри `index.html`:

| Поле | Что это |
|---|---|
| `telegram` | ник Telegram без @ |
| `github` | ник GitHub |
| `discordName` | ник Discord — кнопка «Discord» копирует его (пусто = кнопки нет) |
| `discordId` | числовой ID Discord для живого статуса (пусто = блока нет) |
| `counterKey` | ключ счётчика просмотров (не меняй после запуска, иначе счёт начнётся заново) |
| `playlist` | список треков: название, исполнитель, путь к mp3, обложка |
| `projects` | карточки проектов: название, описание, теги, цвет, ссылка |
| `phrases` | фразы печатающегося текста |

### Как добавить трек
1. Загрузи mp3 в репозиторий, например в папку `music/`.
2. Добавь строку в `playlist`:
   `{ title: 'Название', artist: 'Исполнитель', file: 'music/track2.mp3', cover: 'cover.jpg' },`

### Как включить статус Discord
1. Зайди на Discord-сервер Lanyard: https://discord.gg/UrXF2cfJ7F (просто быть участником — этого достаточно).
2. Discord → Настройки → Расширенные → включи «Режим разработчика».
3. Правый клик по своему профилю → «Копировать ID пользователя».
4. Вставь ID в `discordId`.

## Публикация на GitHub Pages
1. Репозиторий **`TTcux1.github.io`** (Public).
2. Загрузи все файлы (сами файлы, не папку) через Add file → Upload files → Commit changes.
3. Settings → Pages → Deploy from a branch → `main` / `(root)` → Save.
4. Через 1–3 минуты сайт откроется на `https://ttcux1.github.io/`.
