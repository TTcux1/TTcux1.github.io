# TTcux · staff

Личная страница-визитка (тёмный неон, дождь, частицы, печатающийся текст, музыкальный плеер).

## Файлы
- `index.html` — вся страница
- `avatar.gif` — аватарка (облегчённая, 320×320)
- `cover.jpg` — обложка трека и иконка вкладки
- `bg.jpg` — размытый фон
- `music.mp3` — **положи сюда свой трек** (SPACE! (Super Slowed) — NAOMI, DRAWMEDEATH)

## Как опубликовать на GitHub Pages
1. Создай репозиторий с именем **`TTcux1.github.io`** — тогда сайт будет по адресу `https://ttcux1.github.io/`.
2. Загрузи в него все файлы из этой папки + `music.mp3` (Add file → Upload files).
3. Settings → Pages → Source: *Deploy from a branch*, ветка `main`, папка `/ (root)` → Save.
4. Через 1–2 минуты сайт откроется.

## Как поменять
- Фразы печатающегося текста — массив `phrases` в `index.html`.
- Цвета — переменные `--cyan`, `--violet`, `--pink`, `--orange` в начале `<style>`.
- Ссылки — блок `<div class="links">`.
